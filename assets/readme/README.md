# README images

- `header-light.png` and `header-dark.png` (2560×880): the README header, rendered
  at 2× from HTML with the pinned Fontsource JetBrains Mono, Bebas Neue and IBM
  Plex Sans files and the Origami Hash icon (`public/icons/icon-512-v5.png`). It
  follows the social card: white or charcoal ground, the orange top rule, the
  wordmark and a crop of a real Locdoc screen.
- `collaboration.png`, `images.png`, `screenplay.png`, `sharing.png` and
  `history.png` (1600×1200): screenshots of the release built from commit
  `51334f1`, taken in headless Chromium against a temporary state and documents
  folder. The owner, guests, documents and comments are invented. Guest cursors
  are real WebSocket clients; only their name labels, which Locdoc shows on
  hover, are forced visible, and the sidebar's documents path is shown as
  `/home/sam/Documents`.
- The photos in the demo documents are from Unsplash under the
  [Unsplash License](https://unsplash.com/license).
